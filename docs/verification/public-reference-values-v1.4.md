# v1.4｜六張 KPI 與公開產業參考值

日期：2026-10-13。範圍：本機 Demonstration Preview；非 Production、非即時監控、非正式企業營運資料驗證。

## Event｜Owner 變更

本輪要求主畫面顯示六張 KPI，並能在設定中以列表或拖曳方式安排顯示與回歸區；缺少資料處得引入網路上有根據的同產業參考值。

本實作分開三種資料：V1／V2 原始來源、既有明確標示的合成 Demo、公開產業參考。沒有把公開公司的供應商數、年度用水量或稽核率冒充本平台的帳號數、驗證案件或月度實績。

查核方法與限制：使用官方 `esg.tsmc.com`／`esg.tsmc.com.tw` 網域搜尋索引之報告段落。完整永續報告直接開啟因 26 MB 檔案大小受讀取服務限制；上述數值由同一官方 PDF 之索引段落取得，供應商數再由獨立官方責任供應鏈報告交叉查核。不是第三方新聞推算，也未聲稱完整 PDF 逐頁驗證通過。頁碼是報告印刷頁碼。

原始公開參考登錄：`data/demo/rrcc-public-references.json`。離線嵌入：`preview/reference-data.js`（由 JSON 生成）。

## Resolution｜資料與卡片規則

- 每個中心各有八張可用 KPI，預設前六張顯示、後兩張留在回歸區。卡片穩定 ID 是 `{center}-{index}`，切換月份或案場不改變 ID。
- 合成 Demo 前四張原值、名稱與明細保留；新增四張以相同 fixture 按月份及案場重新計算，沒有新增虛構原始來源。
- 原始來源的可用 KPI 不改；缺少營運來源的卡片改成不同且明確命名的「參考｜…」卡，並在 `publicReference.originalMetric` 保留原業務名稱、原 `NO DATA` 與原缺口來源資訊。
- 公開參考不併入 V1／V2，不改變 canonical merged JSON；原始 `RRCC_BIND_DATA_SOURCE` 完整保留。公開值不隨本平台案場／2026 月份變動。
- 公開參考卡只有一筆 2024 年度觀測，沒有補造月趨勢。其來源路由是 `provenance.dataset = public-reference` 與 `/records/{index}`；不假造 V1／V2 provenance。
- 不新增虛構的原始 source 驗證案件、人員或系統事件列；缺資料表可搭配公開參考附表，但需明示仍無本平台紀錄。

## Verification｜資料回歸

`scripts/test-kpi-catalog.mjs`：PASS。驗證 36 組合成 Demo 範圍（四月份 × 全部及八個案場）、12 組原始來源範圍（三月份 × 全部及三個案場），合計檢查 1,404 張 Demo／公開參考卡的數值、ID、來源與詳細資訊。額外驗證：

- Demo 前四張保留，新增卡及四月份 sparkline 由獨立篩選計算驗證。
- 8 張 catalog／預設 6 張設定正確。
- 公開參考 JSON 與離線 JS 一致，來源指向官方 ESG 網域。
- 公開卡保留 2024 年度、單點觀測、非 RRCC 範圍及原 `NO DATA` 欄位識別；每中心不重複同一公開指標。
- 原始 raw source binder 與增量前 12 組快照一致；V1／V2 SHA-256 未變。
- 合成 fixture、merged JSON、公開參考 JSON 均不被 binder 修改。

資料層 PASS 不代表拖曳設定、瀏覽器響應式、動畫或 Owner 視覺驗收通過；這些由本輪主流程獨立記錄。未合併 main，未部署 Production。
